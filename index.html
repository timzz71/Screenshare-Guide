The Screenshare Mindset

As a trial staff member, your job is not to be a hacker. Your job is to be a detective. You are reading the story that a computer's files and logs tell.

Remember this formula: Evidence + Context + Consistency = Decision.
  • Evidence – a file, a log entry, a registry key that you find.
  • Context – was it run at the right time? Does the player have a legitimate reason for it?
  • Consistency – do multiple sources (Prefetch, BAM, Amcache) tell the same story?

A single flagged file is a lead, not a verdict. Strong decisions come from multiple artifacts agreeing with one another and a clear explanation of what happened.

The 5‑Step Walkthrough

This is your procedure. Follow these steps in order. If a result is confusing, pause, save it, and ask a senior staff member.

Explain the check

Tell the player what you will look at, why you are checking it, and how long it should take. Keep the conversation calm and private. Consent is mandatory – they must agree to the process.

Record first

Freeze the player (use /freeze). Start your screen recording before opening any tool. Note down: player name, your name, reason for the check, and the current time. This preserves the chain of evidence.

Check for changes

Before trusting logs and files, check for signs of tampering:

  • Are there cleared event logs?
  • Has the USN Journal been shrunk or deleted?
  • Are Prefetch files missing or set to read‑only?
  • Is Test Signing enabled? (This halts the scan – an environment with test signing on can't be trusted.)

A warning here is a clue, not a guilty result. It tells you that the timeline might be incomplete or altered.

Make a timeline

Use two or more Windows records to answer:

  • What programs ran?
  • When did they run?
  • Do the records agree with each other?

Cross‑reference Prefetch, BAM, Amcache, and the USN Journal. If they don't agree, document the discrepancy.

Review the client

Now, and only now, look at the client itself:

  • Check The Players Mod Folder and versions folders.
  • Run signature‑based client detectors (e.g., MeowClientFucker).
  • Use advanced memory checks only when earlier evidence justifies them – they are slow and invasive.

Artifact Deep‑Dive

You will see these terms in every SS tool. Here is what they actually mean and why we care about them.

📁 Prefetch

A Windows record that shows a program ran and roughly when.

It helps build a timeline. It does not prove what the player did inside the program – only that it launched.

📊 BAM

Background Activity Moderator – another Windows record of program activity.

Use it to confirm or challenge a Prefetch result. Agreement between sources is stronger than one hit.

📋 Amcache

A Windows history of file details that may remain after a file moves or disappears.

It can show that a file was present in the past. It cannot tell you exactly how the player used it.

📝 USN Journal

A Windows record of files being created, renamed, changed, or deleted.

It helps explain missing files and gaps in a timeline. Always compare paths and timestamps with other records.

🔐 Hash

A short fingerprint for one exact file.

If two hashes match, the files are identical. If a file changes by one byte, its hash changes too. Used to identify known cheats.

⚠️ False Positive

A warning that looks suspicious but has an innocent explanation.

This is why one tool result should never be treated as a final verdict – always cross‑check.
Pro tip: Always ask yourself – "Does this artifact make sense with the player's explanation?" If a file is flagged but the player has a legit reason (e.g., a known mod), document it and move on.

Handling the Player

A screenshare is a conversation with proof. How you talk to the player matters just as much as the tools you run.

  • Stay calm and objective – keep comments factual. Never accuse; simply state what you see.
  • Explain each step – tell them what you are about to check and why. This builds trust.
  • Respect privacy – only look at what is relevant to the game. Personal files (photos, documents) are off‑limits.
  • Keep SS details confidential – do not share findings in public chats. This is between you, the player, and all staff members.
Staff standard: Professional, private, precise. No public arguments, no permissions abuse, protect confidentiality.

The Tool Reference

These are the tools we use to find the artifacts mentioned above. They are grouped by what they solve, not just by name.

When to run:

  • Phase 1 (Anti‑forensic): Run first to check if the evidence trail has been tampered with.
  • Phase 2 (Artifact): Build your timeline – Prefetch, BAM, Amcache, USN Journal.
  • Phase 3 (Mods / Macro / Services): Inspect the game client, macros, and system services.
  • Phase 4 (Client): Use signature‑based detectors for known cheat clients.
